# Personal Portfolio Website

A responsive one-page portfolio built with **HTML, CSS and JavaScript** (no frameworks).

## Features
- Responsive layout for mobile, tablet and desktop
- Dark / light mode toggle (remembers your choice)
- Animated typing effect in the hero section
- Mobile hamburger menu and smooth scrolling
- Sections: Home, About, Skills, Projects, Contact
- Contact form with JavaScript validation

## Technologies
HTML5, CSS3 (Grid, Flexbox, CSS variables), JavaScript (DOM, events, localStorage)

## Files
```
portfolio-website/
├── index.html   (page structure)
├── style.css    (design, themes, responsive rules)
├── script.js    (theme toggle, menu, typing effect, form)
└── README.md
```

## How to run
Open `index.html` in any browser. No installation needed.

## Host it free on GitHub Pages
1. Upload these files to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Branch**, choose `main` and `/ (root)`, then click **Save**.
4. After a minute, your site is live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Customize
- Edit your text, skills and project links in `index.html`.
- Change colors in the `:root` block at the top of `style.css`.
- Change the typing words in the `words` list in `script.js`.
- Add your LinkedIn link in the Contact section.
